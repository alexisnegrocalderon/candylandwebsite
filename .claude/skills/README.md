# Skills de motion del Estudio

Copiadas sin cambios de los paquetes MIT de [iart.ai](https://github.com/iart-ai) (© 2026 iart.ai):
`motion-design-skills`, `kinetic-typography-skills` y `tiktok-video-skills`. Se dejaron fuera `after-effects`
(el Estudio no usa After Effects) y las animaciones de muestra.

Son **instrucciones para el agente** (Claude Code), no código del sitio: al pedir «mejora el timing de este estilo» o
«hazme los subtítulos karaoke», el agente las lee y aplica sus reglas sobre Remotion (`motion/`).

| Skill | Para qué sirve en el Estudio |
|---|---|
| animation-principles | easing, duración, escalonado y peso de cada movimiento |
| beat-sync-editing | cortes al pulso y arco de ritmo (establecer → desarrollar → clímax → resolver) |
| short-form-video | gancho en el primer segundo, cortes de atención cada 2–4 s, zonas seguras de Reels |
| caption-animation | subtítulos karaoke: palabra activa, zona segura, legibilidad |
| kinetic-typography | entradas de texto (máscara, golpe, giro, máquina de escribir) |
| countdown-video | cuenta regresiva |
| lower-thirds | etiquetas con nombre/rol |
| logo-animation | firma e intro del logo |
| motion-background / color-motion / shot-composition / motion-art-direction | fondos, color, composición y dirección de arte |
